Шпаргалка по утилитам и командам


1. 📦 Что такое npm?
npm (Node Package Manager) — менеджер пакетов для JavaScript. Он:

Устанавливает библиотеки (React, Vite, React Router и т.д.).

Хранит их в папке node_modules.

Записывает зависимости в package.json.

Аналогия: Это как Maven/Gradle в Java, но для JS.

2. 📦 Что такое nvm?
nvm (Node Version Manager) — менеджер версий Node.js. Он:

Позволяет переключаться между версиями Node.js (например, с 18 на 26).

Устанавливает новые версии.

Решает проблему: «Этот проект требует Node 18, а у меня 26».

Аналогия: Это как SDKMAN! в Java.

3. 📦 Что такое Vite?
Vite — сборщик и сервер разработки. Он:

Запускает локальный сервер (npm run dev).

Собирает проект для продакшена (npm run build).

Дает горячую перезагрузку (HMR) — изменения видны сразу.

Аналогия: Это как Spring Boot DevTools, но для фронтенда.


Основные команды
🛠️ Основные команды:
Команда	Что делает
node -v	Показывает версию Node.js
npm -v	Показывает версию npm
nvm install 20	Устанавливает Node.js версии 20
nvm use 20	Переключается на Node.js версии 20
npm install	Устанавливает все зависимости из package.json
npm install react-router-dom	Устанавливает конкретный пакет
npm run dev	Запускает сервер разработки (Vite)
npm run build	Собирает проект для продакшена (в папку dist)
npm run preview	Просматривает собранный проект локально
git init	Инициализирует Git в проекте
git add .	Добавляет все изменения в staging area
git commit -m "..."	Создает коммит
git push	Отправляет коммиты на GitHub
git pull	Забирает изменения с GitHub
